# Spread the Light — Mission of Luv

A responsive, presentation-style campaign website for Mission of Luv's social media strategy. It is built with plain HTML, CSS, and JavaScript, so it can be published directly with GitHub Pages.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the current branch and the `/ (root)` folder, then save.

## Assets

The original campaign calendar images are kept in `assets/` and displayed in the campaign rhythm section.
